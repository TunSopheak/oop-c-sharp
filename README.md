# OOP -C#
## សេចក្ដីផ្ដើម
  OOP ជាទម្រង់ program ដែលប្រើប្រាស់ objects។\
  នៅក្នុងមេរៀន OOP នេះគ្រាន់តែជាការចងក្រងមួយផ្នែករបស់ខ្ញុំសម្រាប់មុខវិជ្ជា OOAD នៅឆ្នាំទី៤ នៃសាកលវិទ្យាល័យភូមិន្ទភ្នំពេញប៉ុណ្ណោះ។

## Class &Objects
  - Class ជាពុម្ពគំរូសម្រាប់ (ដែលអាច) បង្កើត Object។
  - Class ជា Source Code ដែលក្នុងនោះគេអាចកំណត់នូវ data, properties, methods, events, ... តម្រូវទៅតាម object ដែលយើងចង់បាន។
  - Object ជារបស់ ឬវត្ថុដែលកើតចេញពី Class។\
  ​​  មាន ៣​ របៀបដែលអាចបង្កើត Object ចេញពី Class:
    1. គូស (Toolbox,...,Form)
    2. តាមរយៈការសរសេរកូដ
    3. System ជាអ្នក generates\
    ---
    ```
    Class ClassName{
        //Coding
    }
    ```
